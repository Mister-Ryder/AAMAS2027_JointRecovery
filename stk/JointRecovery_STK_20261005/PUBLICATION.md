# Public-copy and original-source mapping

This update contains completed new STK research materials. It does not change the older manuscript or regenerate experiments. All ten ZIP archives extract relative to this dataset directory. `PUBLICATION_MANIFEST.json` records original and public-copy SHA256 values, assets and the scientific source closure for all twelve historical capsules. Unused old logistics/runtime scripts, transport containers and bytecode are excluded; stage evidence, labels, complete geometry, failure/late/N/A records and checkpoints are retained.

The original SSH login defaults in `code/cloud_runner.py` are generalized to `JR_SSH_HOST`, `JR_SSH_PORT`, `JR_SSH_USER` and `JR_SSH_KEY`. Public cloud helpers are optional historical orchestration examples, and require your own server, Python/native paths and host-key verification. No credentials or private key bytes are included. Original scientific freeze hashes are historical bindings and are not replaced with the public documentation hashes. The nine quality scientific source files preserve their executed bytes.

CHILS is distributed with its official LICENSE and exact native provenance in `vendor/CHILS/PROVENANCE.json`. The top-level repository license does not supersede vendored dependencies. On Linux restore executable permission using `chmod +x vendor/CHILS/CHILS`.

See the final report for scope limits and incomplete solver outputs; uploading this material does not establish performance superiority or conference acceptance.
