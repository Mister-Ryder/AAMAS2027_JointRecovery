# JointRecovery 独立执行包

版本：2026-10-05 v2.0。

先阅读 `JointRecovery_STK_Priority_Plan.docx` 第1页，再由工程师执行参数JSON中的 P0。

首批：2个原始12站/72小时机会库，派生8/12站与170/340/680秒共12张图；先200/1000毫秒有限恢复探针。

本包不依赖其他团队、历史数据、旧资源映射或旧约束实现。问题限定为完整几何可见接触、收益等于链路时长；不生成任务、不切片、不重赋权。

## 文件

- Word方案：8页分阶段执行单，包含完整模型、参数、验收和停止线。
- `JointRecovery_parameters.json`：所有12个来源的逐卫星初始轨道元素、完整站点表、来源划分与阶段配置。只执行P0指定来源即可，不要求一次创建全部场景。
- `SHA256.json`：最终交付文件哈希。

## 数据状态

所有场景均为待仿真参数。本包没有运行STK、训练模型、获取新证书或测得新算法优势。参数JSON不是STK原生场景文件；工程师按其安装版本创建对象和计算Access。

## 优先级

P0先检查机制信号；P1用最小学习/执行闭环；P2冻结后新来源确认；P3才扩大几何和规模。开发阈值用于安排投入，不用于按测试输赢删样本。所有来源中的配置、子集和状态保持同一划分。
